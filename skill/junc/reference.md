# Reference

Generated by `cargo xtask skill-ref` from the `junc` command definitions
and its error table; do not edit by hand.

## JSON output

With `--json`, every command prints one document:

```json
{"junc": 1, "ok": true, "revision": 42, "data": {}}
{"junc": 1, "ok": false, "error": {"code": "E_CONFIG_RANGE", "message": "volume is 900",
 "hint": "Volume is a percentage from 0 to 150.", "location": {"file": "…", "line": 7, "column": 10}}}
```

`revision` is the config revision after the command (pass it to
`--expect-revision`). `junc describe --json` → `data`: `state`, `revision`,
`config_file`, `config_error[]`, `junctions[]`, `capture_apps[]`, `defaults`,
`candidates[]`. `junc apply FILE --dry-run --json` → `data.plan`: `summary[]`,
`actions[]`, `complete`, `deferred[]`, `junctions[]`.

## Error codes and exit codes

| Code | Exit | Meaning and what to do |
| --- | --- | --- |
| `E_USAGE` | 2 | Wrong command or arguments. See `junc --help` or the command's help. |
| `E_CONFIG_SYNTAX` | 3 | The file is not valid TOML. Fix it at `location`. |
| `E_CONFIG_SCHEMA_NEWER` | 3 | The file is for a newer JUNC. Update JUNC. |
| `E_CONFIG_SCHEMA_INVALID` | 3 | `schema` is not a known version. Use `schema = 1`. |
| `E_CONFIG_UNKNOWN_KEY` | 3 | A key the format does not have. The hint names the closest one. |
| `E_CONFIG_MISSING_KEY` | 3 | A required key is missing (for example `id` or `name`). |
| `E_CONFIG_INVALID_VALUE` | 3 | A value has the wrong type or shape. |
| `E_CONFIG_ID_FORMAT` | 3 | An id must be lowercase letters, digits and `-`. |
| `E_CONFIG_ID_DUPLICATE` | 3 | Two items share an id. Rename one. |
| `E_CONFIG_RANGE` | 3 | A number is out of range (volume 0–150, Bus 1–64 channels, rate 44100–192000). |
| `E_CONFIG_LINK_CHANNEL` | 3 | A link names a channel that does not exist. |
| `E_CONFIG_DEFAULT_DUPLICATE` | 3 | Two Junctions claim the same default role. Keep one. |
| `E_CONFIG_MATCH_KIND` | 3 | A `match` is empty or mixes kinds (app keys, `device`, `monitor`, `junction`). |
| `E_CONFIG_JUNCTION_UNKNOWN` | 3 | A nested Junction id does not exist. |
| `E_CONFIG_CYCLE` | 3 | Nesting would make audio feed back. Remove one Junction Input of the loop. |
| `E_CONFIG_CABLE` | 3 | A Cable needs exactly one app Input and `[junction.cable] to = { … }`. |
| `E_CONFIG_SLOT_OUTSIDE_PRESET` | 3 | Template slots are only for presets; use real values in the config. |
| `W_CONFIG_MANY_INPUTS` | 0 | Warning: many Inputs on one Junction. Accepted. |
| `E_NOT_FOUND` | 4 | No such Junction, Input, Listen output, link or unit. The hint suggests the closest name. |
| `E_CONFIG_CONFLICT` | 5 | The config changed since the revision you read. Read it again and redo the change. |
| `E_DAEMON_UNAVAILABLE` | 6 | juncd is not running. `systemctl --user start juncd`. |
| `E_DBUS` | 6 | No session bus, or the call failed on the bus. |
| `E_PIPEWIRE_UNAVAILABLE` | 7 | PipeWire is not running; plans need the live graph. `systemctl --user start pipewire wireplumber`. |
| `E_NEEDS_CONFIRMATION` | 8 | A destructive command without `--yes`. Ask the user, then pass `--yes`. |
| `E_WRITE_FAILED` | 1 | juncd could not write the config file. Check permissions of the config directory. |
| `E_EDITOR` | 1 | The editor of `junc config edit` failed. Set $EDITOR. |
| `E_NO_SYSTEMD` | 1 | `junc service` needs systemd. Start juncd from the session's autostart instead. |
| `E_SERVICE` | 1 | systemctl failed. See `systemctl --user status juncd`. |
| `E_SKILL` | 1 | The skill could not be linked; the message names the folder. |
| `E_INTERNAL` | 1 | A bug or a version mismatch between junc and juncd. Report it with `junc doctor`. |

Exit 0 means success.

## Commands

### `junc`

```text
Route audio between apps and devices with Junctions

Usage: junc [OPTIONS] <COMMAND>

Commands:
  list       List Junctions and Cables with their status
  status     Show the daemon, or one Junction in detail
  create     Create a Junction or a Cable
  rename     Rename a Junction (its id stays)
  duplicate  Copy a Junction
  delete     Delete a Junction and its routing
  enable     Turn a Junction on
  disable    Turn a Junction off
  toggle     Turn a Junction on if it is off, and off if it is on
  switch     Turn a Junction on and make it the default input or output
  default    Make a Junction the default input or output, or stop that
  volume     Set the volume of a Junction, one of its Inputs, or a Listen output
  input      Add, remove, enable or disable Inputs
  bus        Add or remove Bus channels
  link       Link an Input channel to a Bus channel (`mic:1 2`), or a Bus channel to a Listen output channel (`1 speakers:2`)
  unlink     Remove a link (same arguments as `link`)
  listen     Add or remove Listen outputs
  describe   Everything an agent needs in one JSON document
  schema     Print the JSON Schema of junctions.toml
  config     Find, check or edit the config file
  apply      Apply a whole config file (`-` reads stdin)
  doctor     Check PipeWire, WirePlumber, pipewire-pulse, JACK, the clock and juncd
  service    Start juncd at login, or not (`systemctl --user` on juncd.service)
  skill      Make the JUNC skill visible to your coding agents, or not
  help       Print this message or the help of the given subcommand(s)

Options:
      --json         Print one JSON document instead of text
  -q, --quiet        Print nothing on success
      --no-color     Do not color the output
      --lang <CODE>  Language for messages (e.g. de, pt_BR)
  -h, --help         Print help
  -V, --version      Print version
```
